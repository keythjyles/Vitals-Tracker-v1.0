# CapLock operating notes

Read the [GS video tools master plan](../../GS_VIDEO_TOOLS_MASTER_PLAN.md) and the [root operating rules](../../../AGENTS.md) before editing this app.

Assemble multiple independent caption, graphic and media placements. Keep Layer 0, source trim, the editable timeline and the existing CapLock project and export paths.

Match AspectLock for common playback, Toolbox, Scribe, opacity and keying controls. Preserve the approved built-in caption lock, local and saved-project entry, undo, draft recovery, editable tracks, and prior project compatibility.

Follow the master plan's approval process for changes to established behavior. When an approved change affects another tool or a shared contract, update the affected notes and verify those paths in the same work.

See the [CapLock behavior and release notes](README.md).
