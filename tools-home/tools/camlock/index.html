Camera controls

Lock stage to arm the viewport. The first finger directs the camera: move down and the picture moves up. A second finger rotates around the first. Lift either or both fingers freely; Action continues. If the primary finger lifts, the remaining finger becomes the direction controller without a jump.

Pause, navigate to a correction point, then start Action to replace only the path from that time onward. Navigation preserves the path. Raw movement uses linear interpolation with no smoothing.
