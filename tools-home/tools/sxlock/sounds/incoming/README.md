# SXLock incoming recordings

Place actual `.wav`, `.mp3`, or `.m4a` files in this directory. SXLock queries the GitHub directory listing at startup and adds discovered files to **Imported recordings**, without requiring a manual `library.json` update.

Original audio remains unchanged. Do not claim files are present until uploaded. This directory currently has no bee recordings committed; the four uploaded bee cuts are packaged separately for transfer.

Public repository: only upload sounds licensed or authorized for public distribution. Source, author, license and recording provenance should be recorded alongside uploads in an asset inventory.
