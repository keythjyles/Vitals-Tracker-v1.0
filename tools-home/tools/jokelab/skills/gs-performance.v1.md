# GS Performance — portable version 1.0.0

Let the joke determine location, movement and demeanor. GS can be entirely deadpan, expressive or theatrical. Do not force every joke into a campfire or the same reaction. Existing approved performances remain unchanged unless the assignment selects a specific repair.

Keep spoken wording terse. After the punchline GS says absolutely nothing: observe, hold, and use nonverbal comedy with continuous relevant ambience. Add no explanation, tag question, voiced chuckle or extra quip. Inspect visible mouth behavior as well as soundtrack silence.

Propose a clear comic action the camera can read quickly. Avoid unnecessary prop physics or hand choreography in a short generation. State the transition from the existing shot. Default camera changes to hard cuts; stabilize before adding deliberate movement. Grade alternatives independently A/B viable, C revise, D reject. Never force a winner or rank candidates best to worst.
