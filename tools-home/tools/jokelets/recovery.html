Factory and Publication builder save imported files and edits inside this browser. Those saves do not upload to Drive. SxLock keeps its own project; export its project and finished video separately.

  1. In the Factory, choose Save / share project. Keep the JSON file in your Production Drive.
  2. Open Drive and confirm the file arrived with a current date and nonzero size. Keep an earlier version too.
  3. To recover on another device, open Factory and choose Import project. Check the imported clips and play your assembly.
  4. For a finished publication, keep both the project JSON and the exported video. Before clearing browser data, confirm both copies.
