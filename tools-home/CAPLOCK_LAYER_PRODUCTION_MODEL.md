# CapLock / GS layered production model — owner direction, October 28, 2026

## Preserve the bed permanently

The original bed remains unchanged throughout editing AND publishing. Preview composes independent sources temporarily. Explicit final rendering creates a NEW publication master; it never writes effects, captions or another encoding generation back into the original bed. Reopening, saving, sharing a project or previewing is not a flattening operation. Preserve the editable project and original sources after final export.

Repeatedly exporting one tool's flattened output into the next can accumulate encoding/color changes. The target production model retains separate sources and edit instructions until one deliberate final composite/encode. An already-approved finished bed may be loaded as a source, but do not repeatedly bake new stages into it. Browser export can require re-encoding; final picture/audio/color/frame-count acceptance must be measured, not described as lossless.

## Four logical production roles

- Bed: original source picture and its existing approved soundtrack.
- Animation: transparent animations, graphics and inset or enlarged video.
- Sound: independent recordings, voice, music, ambience and effects.
- Captions: transparent prebuilt caption video and/or editable native text.

These are logical roles, NOT new Z0–Z3 assignments. One role can contain many media objects. Each object retains stable identity, source reference, integer production-frame boundaries, source trims, order, visibility/mute, edit/transform lock, position, aspect-preserving scale, opacity and explicit 2D rotation as applicable. Permit hiding, removing project references, reordering and editing without altering source media. Oversized/inset clips are legitimate; output-frame cropping belongs to composition, not destructive source modification.

A prebuilt transparent caption/animation video can be reused as an independent layer over another bed. Keep its own source, alpha, frame rate and audio policy explicit. The media type and logical production role are separate concepts. Viewport zoom/pan is always independent of render geometry. Ordinary move/resize/pinch cannot rotate; Rotate must be selected and Square resets exactly 0 degrees.

Global visual protocols guide Gemini generation; approved first looks can be reused, and individual segments can choose an entirely independent direction. Preserve exact transcript/word directions and the generated clips separately. Do not regenerate or flatten approved layers merely because a neighboring layer changes.

## Planned recording / GS voice route

Preserve the user's original live recording as an independent source. Retain an editable transcription and verified alignment alongside it. The desired future voice stage converts the RECORDED PERFORMANCE to the approved GS voice so phrasing/pauses come from the recording; transcription is a companion, not a requirement to reconstruct delivery from text prompts. Retain provider output and the original recording separately as sound-layer assets.

This is a FUTURE requirement, not a claim of implemented browser recording, transcription, voice conversion or ElevenLabs API support for a particular model. Verify current official provider capability and establish a versioned approved procedure before implementation. Do not silently substitute the existing TTS procedure/model for a performance-preserving voice-conversion route. Preserve existing GS voice references and procedural/budget rules. The owner said “eventually”; this editor work authorizes no paid voice generation, upload for voice training, new clone, retries or service purchase.

## Current implementation boundary

CapLock R2 implements transcript/word directions, Gemini briefs, separate source bed plus media-clip preview objects, optional native captions, frame placement, clip visibility/removal/order/geometry, explicit Rotate, undo and version2 project recovery. It does not flatten or encode the bed at any editing step. Existing AspectLock/SxLock/PreviewLock engines and masters remain unchanged.

R2 does NOT yet implement the full four-role track UI with every bed/group mute/lock operation, a shared final renderer across the production tools, finished-video export, durable cloud project saving or the future recording/voice route. Native overlay preview has browser seek/scheduling tolerance. These remain engineering stages; do not claim them complete from the architecture record. Implement them through reusable adapters while preserving the locked existing production tools.
